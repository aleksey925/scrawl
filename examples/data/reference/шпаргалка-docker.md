# Шпаргалка по Docker

Команды, которые нужны чаще всего.

- [Запуск](#запуск)
- [Логи](#логи)
- [Очистка](#очистка)

## Запуск

Поднять все сервисы в фоне и пересобрать образы, если код изменился:

```bash
docker compose up -d --build
```

## Логи

Смотреть логи одного сервиса с последних ста строк:

```bash
docker compose logs -f --tail 100 api
```

## Очистка

Удалить остановленные контейнеры, неиспользуемые сети и образы без тегов:

```bash
docker system prune
```

Про сеть между контейнерами - в [отдельной заметке](сеть-docker.md), её ещё
нет. Другие команды - в [shell cookbook](shell-cookbook.md).
