# PlantUML

PlantUML diagrams of many types and sizes. The browser draws them
itself; the server draws them for an export and for `scrawl render`.

- [UML](uml.md): sequence, class, activity, state, use case, component,
  deployment, object and timing diagrams.
- [Architecture](architecture.md): C4, AWS, Azure, Kubernetes, tupadr3
  icons and ArchiMate from the standard library.
- [Data and plans](data-and-plans.md): mind map, WBS, Gantt chart, JSON,
  YAML, ER, a UI mockup, EBNF and a regular expression.
- [Look](decor.md): themes, colors, icons, emoji, tables in text, and a
  very wide and a very small diagram.

The shortest diagram, with no `@startuml`:

```plantuml
Reader -> Note : open
```
